# **项目一：智能旅行规划助手**

## 1. **业务背景**

旅行攻略搜索时间长，去玩通常要花几个小时到一天的时间去做攻略，花了这么多时间可能确定的行程还不合理，最后还踩很多坑

而且想要出去旅游，机票，酒店和当地景点的查询较为分散，信息分散，需要去各个平台去手动整合，比如携程预订机酒，小红书找景点攻略，美团找旅行餐厅，在高德确定行程路线；

还有无法根据个人去定制化旅行计划，所有旅行规划趋向大众化，无法更加个人偏好进行个性化的定制旅游，比如相对小众的旅游路线

## **业务需求分析**

智能旅行规划助手可以帮你推行个性化的旅游方法，根据你个人偏好和预算帮你规划一整套旅行计划，从出行交通帮你选择飞机或者高铁或者汽车改，根据你的预算进行酒店预订，到目的地一整套游玩计划，帮你规划整个旅程的吃喝玩乐，支持你进行对应的行程编辑

最后是难以调整，当你想更改行程的时候，可能需要重新规划整个行程，因为景点的顺序，时间安排，预算都是相互关联的。

AI技术为解决这些问题提供了新的可能，想象一下，你需要就告诉我‘我想去泰国玩3天，喜欢历史文化，预算中等，’系统就能自动为你生成一个完整的行程计划，包括每天去哪些景点，在哪里吃饭，住哪个酒店，需要多少预算，而且计划很容易调整，你可以直接删除不喜欢的景点，或者不喜欢的酒店，系统会自动更新地图和预算。

旅行助手包含的要素：

1. 出发地->目的地+旅行时间

2. 获取天气信息

3. 出行交通（机票/高铁/开车）

4. 输入个人的偏好+给出整个行程的预算

5. 景点

6. 酒店

7. 到景点吃喝玩乐出行计划（必玩必买必吃的当地特色）

8. 出现注意事项（当地文化风俗/需要携带的东西）

9. 特色：任意添加的行程地图

10. 最终的导出格式

### **核心功能**

1. 行程规划：用户输入目的地，日期，偏好，系统自动生成包含交通出行，酒店预订，景点推荐，餐饮的完整行程计划，对应的特色的标注

2. 支持PDF，PNF图片等格式导出

3. 预算计算：自动计算交通，酒店，餐饮，景点门票费用，显示

4. 在地图上标注景点位置，绘制游览路线，让行程一目了然

5. 行程节点编辑：添加，删除和修改景点，实时更新地图（这个功能好难）

6. 对于风土人情有一些额外的注意事项

## **技术架构设计**

前端：

输入：用户通过输入出发地，目的地，日期，预算，个人偏好

输出：

l 详细的行程规划，精确到某天什么时间点去哪个地方，在哪里吃饭，休息多长时间啊，乘坐什么交通工具(精确的程度可以调节)

l 吃喝玩乐，景点的具体行程地图

l 预算统计表

l 支持格式导出

后端：

如何进行预算分配？LLM执行吗？

LLM统一调用工具进行信息查询，可以预算的计算

1. 调用天气工具查询天气

2. 调用交通出行工具(携程)查询机票，高铁票，酒店信息+价格费用

3. 调用traily查询景点和门票信息

4. 在游玩的景点的附近查询餐饮和交通的信息

5. 调用计算器进行预算的计算和生成

6. 个人偏好：标签选择或者手动输入
如果是标签选择的话：自然风光，小众路线

2. 工具调用（tool_calling,MCP）
